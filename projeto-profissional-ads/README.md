# Sistema para Assistências Técnicas
Sistema desenvolvido em Python como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS).

O sistema tem como objetivo auxiliar no gerenciamento de uma assistência técnica, permitindo o controle de clientes, equipamentos, ordens de serviço, técnicos e estoque de peças.

## Funcionalidades:

- Cadastro e gerenciamento de clientes
- Cadastro de equipamentos
- Abertura e gerenciamento de ordens de serviço
- Controle do status das ordens de serviço
- Gerenciamento de técnicos
- Distribuição de ordens de serviço entre os técnicos de forma automatizada
- Controle de estoque de peças
- Consulta de ordens de serviço
- Histórico de serviços realizados
- Finalização e cancelamento de ordens de serviço
  
## Tecnologias utilizadas
- Python
- Estruturas de dados como:
  - Dicionários
  - Listas
  - Filas (deque)
